## 三、解析器结论

### 规则要点（`parse_folder_name_lenient`）

1. **作者**：取第一个 `[..]`（必须方括号）；无作者格式容忍（author 留空）。相邻两个方括号 `[标题][作者]`（U2 格式）→ 作者取第二个、series 取第一个。
2. **主名**：作者后、下一个括号前的内容**原样保留**（不做中英拆分、不截断，如 `カムイ伝 第二部`、`惊爆危机 Σ`、`全职猎人 HUNTER×HUNTER`）；主名为空时取末尾残留片段（如 `(C97) [社团名 (作者名)] 标题` → 标题）。主名中的内联卷标（`第01-12巻`）会被剥离。
3. **括号内容分类**（支持 `[]` / `()` / 全角 `（）`，嵌套取最内层）：
   - **方括号**：命中 tag 黑名单 → tags；含卷标 → 整段作 vol_info；其余 → aliases（别名参与搜索）。
   - **圆括号**：含卷标 → 只取卷号部分（`V08全` 的 `全` 并入卷号），卷号之后的全部内容按空格拆成 tags（`+` 保留）；无卷号 → 整段按空格拆 tags，不再进 aliases。
4. **卷号识别正则**（宽松）：`V1`/`Vol.1`/`volume 1`/`卷1`/`册2`/`期3`/`chapter 1`/`ch.1`/`第01-12巻`（范围）/`1巻`/`二十卷`/`十話` 等；支持中文数字与全角数字（转半角后取值）。**C97 是展会码（tag），C1-C9 才是卷标**。
5. **卷数取值**：卷标中数字取最大（`Vol.01-Vol.24`→24，`Vol.16 - Vol.17`→17，`第01-12巻`→12）；无卷标 → 0；短篇固定 1。
6. **完结判定**：卷信息含 `全/完结/完/end/completed/fin/complete` → 已完结；tag 提示词（`完结` 等，多字）且无连载提示 → 已完结；无卷信息默认未完结（连载）；`连载中/ongoing/未完` → 连载。缺卷说明 `缺...` 前缀 → 一律进 tags（不进 vol_info、不进 aliases）。
7. **附加内容**：卷标中 `+` 之后的部分 → extras（`V02全+原画集` → extras=原画集），`+` 原样保留在 tag（2026-08-09 规则）。
8. **tags/aliases 均去重**（`[日] [日]` → `[日]`）。
9. **返回结构**：`author / series / aliases / tags / vol_info / total_volumes / vol_type / complete / has_extras / extras`，与旧 `parse_folder_name` 兼容（旧函数不受影响）。

### 已知边界（支持 / 不支持）

- ✅ **支持**：U2 全括号、nyaa 日文卷范围、英文 Vol. 范围、V 直接跟数字、中文数字/全角数字/中文卷范围、短篇、完结+附加、展会码、嵌套括号、缺卷说明、汉化组 zip、jmcomic ID 全名保留。
- ⚠️ **部分支持**：
  - `[ENG] One Piece - Vol. 106 (...)`：`[ENG]` 被当作作者（第一个方括号必为作者），series 仍正确；圆括号内英文 tag 按空格拆成单词（`FULL COLOR Digital Colored Comics` → 5 个 tag），较碎。
  - U2 变体 `[天下][C.C]`：黑名单外的方括号内容（`天下`、`C.C`）进 aliases 而非 tags——若期望是版本/来源标记需扩充黑名单。
  - `第X话`（X 为中文数字且无阿拉伯数字）不识别为卷（`《作品名》第X话` 整体留在 series）。
- ❌ **不支持**：
  - 空名 / 纯空白 → 返回 `None`。
  - 直角括号 `【】` 不参与解析：`【BLVEFO9】喂我吃吧 老師!` 整体保留为 series，作者为空。
  - `C97/C99/C100` 等展会码不会当卷数（total_volumes=0）。
  - 卷号 `V０４` 的 vol_info 保留全角原文（不归一化，仅卷数取值时转半角）。
