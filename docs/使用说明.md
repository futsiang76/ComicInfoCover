# ComicScratch 使用说明

> 版本：v1.0.0 ｜ 更新日期：2026-08-09 ｜ 适用平台：Windows

## 一、软件简介

ComicScratch 是一款免费的本地漫画库整理工具：扫描你的漫画文件夹，从公开数据源自动匹配书名、作者、出版社、简介、封面等信息，写入压缩包内的 ComicInfo.xml，让 Calibre、Kavita、Tachiyomi 等阅读器都能正确识别收藏。它只负责整理，不提供下载或在线阅读。软件完全免费，觉得好用可自愿打赏支持。

## 二、快速上手

1. **选择漫画目录**：启动后按引导选择漫画库，之后可在右上角设置中切换。
2. **选择数据源**：默认 Bangumi，可在设置中补充 ComicVine Key 作备用；不填也能用。
3. **开始扫描**：点「开始扫描」，软件在后台逐本匹配，跑完自动进入结果页。
4. **查看结果**：结果按「匹配成功 / 待补漏 / 失败」分组，先处理后两组。
5. **编辑保存**：双击条目修改信息，确认后点「批量保存」，rar / cbr 自动转为 CBZ。

## 三、数据源说明

- **Bangumi（默认）**：中文覆盖好，公开搜索无需 Token；填入 Token 匹配更准。
- **ComicVine**：备用源，需在设置中填 API Key，Bangumi 找不到时自动尝试。
- **其它网络来源**：无需配置，作为补充自动使用。

## 四、扫描模式

- **全匹配**：对全部漫画逐一匹配，适合首次整库整理。
- **补漏**：只处理上次未匹配或信息不完整的条目。
- **修正**：仅复查指定条目的匹配结果。
- **手动 ID**：已知编号时直接指定，跳过搜索，最精准。

## 五、结果编辑

双击条目可编辑书名、作者、简介、标签等字段，也可改用手动搜索或换源重试。封面裁剪可手动调整封面位置，开启「裁剪定位记忆」后，同类漫画沿用上次的裁剪方式。

## 六、常见问题

1. **匹配不到怎么办？** 试试「作者 + 书名」组合或换数据源再搜；都不行就手动填写。冷门资源搜不到属正常，跳过不影响其它条目。
2. **API Key 在哪填？** 点右上角齿轮打开设置，在「源配置」中填 Bangumi Token 和 ComicVine Key。
3. **rar / cbr 能处理吗？** 能。会自动转为 CBZ 后写入元数据，转换后大多阅读器可正常识别。
4. **扫描很慢正常吗？** 正常。首次整库需逐本联网匹配，耗时取决于库大小与网速，可先拿小目录试跑。
5. **会弄坏漫画吗？** 不会。只写入或修改 ComicInfo.xml，不碰图片；首次使用前建议备份。
