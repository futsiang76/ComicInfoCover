# ComicScratch 首次使用指南

ComicScratch 是一款帮你整理漫画库的小工具：它扫描你的漫画文件夹，自动从 Bangumi、ComicVine 上查找每部漫画的信息（书名、作者、出版社、简介、封面等），写进漫画压缩包里的 ComicInfo.xml，让各种阅读器和刮削器（Calibre、Kavita、Tachiyomi 系列等）都能正确识别你的漫画。

本指南面向第一次使用的普通漫友，按顺序往下看，10 分钟就能读完。需要说明的是：这个工具只负责「整理元数据」，不负责下载漫画、也不负责在线阅读。

## 一、快速开始（3 分钟上手）

### 第 1 步：打开软件，选漫画库目录

双击 ComicScratch.exe 启动。首次启动会弹出「轻引导」窗口，只需要做一件事：

1. 选择你的漫画库目录（存放漫画文件夹或压缩包的地方，例如 `D:\Comics`）
2. 点击「开始使用」

这一步是**唯一必做**的设置，其他全部可以不管。

> 小提示：如果你有多个漫画库，引导里先随便选一个，之后随时可以在主界面右上角的设置里切换。

### 第 2 步：开始扫描

主界面会显示你刚才选的目录。确认无误后，点击「开始扫描」：

- 扫描在**后台运行**，界面会有小猫动画提示，不用一直盯着
- 软件会读取每个漫画文件夹 / 压缩包的信息，并尝试在网络上匹配对应的漫画条目
- 扫描期间建议不要往漫画库里拷贝、移动或删除文件，以免结果不完整

### 第 3 步：查看扫描结果

扫描完成后会自动切换到「结果页」，所有漫画按匹配状态分组展示。

到这里，第一次使用就算完成了——剩下的都是可选操作。想进一步整理，请看第三节「完整整理流程」。

## 二、设置（可选，不设置也能用）

点击主界面**右上角的齿轮图标**打开设置。默认配置已经能正常使用，下面按分区简单说明，按需了解即可。

### 源配置

- **Bangumi Token**：可选。不填也能用（公开搜索不需要 Token）；填了可以获得更准确的匹配结果和更完整的数据
- **ComicVine Key**：可选。作为备用数据源，当 Bangumi 上找不到对应条目时，会用 ComicVine 尝试匹配

一句话：什么都不填也能用，填了只是让匹配更准、命中率更高。

### 扫描配置

匹配阈值、请求超时等参数。一般不用改，默认值适合绝大多数漫画库。只有当你发现匹配结果明显偏松（乱匹配）或偏严（大量漏匹配）时，才值得来这里微调。

### 扫描结果处理

- **保存格式**：默认「保持原格式」。zip 保持 zip、cbz 保持 cbz；**rar / cbr 会自动转换为 CBZ**（因为 rar 格式无法直接写入 XML 文件）
- **删除旧文件**：勾选后，格式转换时会删除原压缩包，只保留新文件。建议确认整理结果没问题后再勾选

### 应用目录

- **默认漫画目录**：启动时预选的目录，可以在这里修改
- **记住上次路径**：勾选后，下次启动自动打开上次使用的目录，不用重新选

### 封面裁剪

**裁剪定位记忆开关**。如果你手动调整过封面裁剪的位置，开启后，下次对同类漫画裁剪封面时会沿用上次的定位方式，省去重复调整。

## 三、完整整理流程

下面是一次完整的「全库整理」流程，照着走就行：

### 第 1 步：全库扫描（无人值守）

在扫描页选择整个漫画库目录，点击「开始扫描」。这一步是无人值守的：后台运行，大库可能比较久，期间可以去做别的事，跑完会自动切到结果页。

### 第 2 步：结果页体检

扫描完成后，结果页会把所有漫画分成几组：

- **匹配成功**：已自动找到并填好元数据的条目，扫一眼有没有明显错误即可
- **待补漏**：部分信息缺失、或匹配结果不够确定的条目
- **失败**：没有匹配到任何结果的条目

先看整体比例：匹配成功占大多数就说明库很健康，重点处理剩下的两组。

### 第 3 步：补漏（处理未匹配条目）

按顺序处理「待补漏」和「失败」的条目：

1. **手动搜索**：输入更准确的关键词重新搜索，试试「作者 + 书名」的组合
2. **换源**：Bangumi 找不到，就换 ComicVine 再搜一次，反之亦然
3. **本地手填**：以上都不行，就手动填写书名、作者等基本信息，至少保证阅读器能识别
4. **跳过**：实在搜不到（比如冷门同人本、自扫本），直接跳过即可，不影响其他条目

注意：这一步不用追求 100% 命中。冷门资源搜不到是正常现象，跳过不丢人，也不影响其他漫画。

### 第 4 步：个别修正

对匹配结果不满意、或者想微调的条目，**双击条目**进入编辑：

- 编辑 XML 字段：书名、作者、出版社、简介、标签等
- 修改 Title：控制漫画在阅读器里显示的名称

改完记得保存当前条目的修改，再继续处理下一条。

### 第 5 步：保存收尾

所有条目检查完毕后，点击「批量保存」。保存格式按照设置里「扫描结果处理」的配置执行：

- 原格式的漫画保持原格式不变
- rar / cbr 会自动转成 CBZ

保存完成后，用你的阅读器打开漫画库，就能看到整齐的书名、作者和简介了。

## 四、常见问题

### rar / cbr 漫画能处理吗？

能。rar 和 cbr 会被自动转换为 CBZ 后再写入元数据，转换后的文件能被大多数阅读器正常识别。

### 不填 API Key 能用吗？

能。Bangumi 的公开搜索不需要 Token；ComicVine Key 只是可选的备用源，填不填都不影响基本使用。

### 扫描时能关窗口吗？

不能。扫描和匹配都在软件后台运行，请让它跑完。中途关闭可能导致本次结果丢失，需要重新扫描。

### 扫描很慢正常吗？

正常。首次扫描整个漫画库需要逐本联网匹配，耗时取决于库的大小和网络速度。可以先拿一个小的测试目录熟悉流程。

### 会把我的漫画弄坏吗？

不会。软件只往压缩包里写入 / 修改 ComicInfo.xml，不会动里面的图片。如果还是不放心，第一次使用前先备份，或者用小目录试跑一次。

### 保存格式选错了能改回来吗？

能。随时可以在设置里改回来，重新保存即可。

### 封面变了是怎么回事？

部分数据源会提供封面图片，软件可能用它替换压缩包内的封面。如果不想要这个行为，可以在「封面裁剪」或相关设置里关闭。

### 匹配到错误的漫画怎么办？

在结果页找到该条目，双击进入编辑，改用手动搜索或换一个数据源重新匹配；都不行就本地手填。

### 软件是免费的吗？

是。ComicScratch 是免费的开源工具，不收费、无内购。
